# Q20.12 Conv1 direct-writeback validation

Date: 2026-10-11. **Conv1 MAC II=1 restored**, with identical output words
and unchanged numeric contract. This resolves the scheduling regression in
[the first Q20.12 Vitis checkpoint](p3-q20-12-vitis.md). Default Q24.8 and
the existing deployed overlay remain unchanged.

## Change and provenance

Code commit: `5f76e4e0007db5f4b28841687273761777bc31a4`, branch
`optimize/official-q20-12`. The validation began from `7e00255` with the
candidate source patch; that exact source is captured by the code commit.
Component manifests record the base revision and actual source hashes.
The compiled `hls/src/srcnn_axis_dataflow.cpp` SHA-256 is:

```text
81a31823916065de1beb7e5e715189be036d4f19f7a5235fe52d9e5ea1bd4672
```

Only the Q20.12 streaming Conv1 MAC writeback changes:

```cpp
// Before: helper takes the accumulator by reference and executes +=.
arithmetic::accumulate_product(sums[lane], weight, window_value);

// After, under SRCNN_HLS_OFFICIAL_Q20_12 only:
sums[lane] = sums[lane] + weight * window_value;
```

The actual code retains the existing weight indexing. No product register,
new pragma, dependence override, UNROLL factor, FIFO, padding or MAC-order
change was introduced. Conv2/Conv3 and the legacy float/Q24.8 path retain the
original helper. Data is still signed 32/20 Q20.12, AP_RND_CONV/AP_SAT;
accumulators remain 31/37/44 bits with AP_TRN/AP_SAT. The product is not
pre-narrowed or clamped separately.

The installed vendor `etc/ap_fixed_base.h` defines `operator+=` via
`OP_ASSIGN_AF(+)` as `*this = operator+(op2); return *this;`. Thus direct
assignment retains the same addition and saturated accumulator conversion;
it exposes a different structure to HLS rather than removing saturation.

## Schedule evidence

Both before/after verbose schedules and the new binding report are saved.
The old report placed the accumulator add and saturation selections in
state 6 (critical path 3.226 ns), then the accumulator store in state 7
(0.427 ns). State 6 included both `select_ln20_68` and an extra 31-bit
`sums` select. The distance-1 feedback crossed these two scheduled states,
and `HLS 200-880` reported II=1 could not be enforced.

With direct writeback, state 5 contains the 64-bit add, saturation compare,
31-bit saturation select and accumulator store together (3.235 ns).
The extra `sums` select is absent from that critical path. There are five
pipeline states rather than seven, and no Conv1 II warning. This evidence
locates the regression in the generated reference-helper feedback structure;
it does not identify a weight RAM port conflict or justify disabling AP_SAT.
